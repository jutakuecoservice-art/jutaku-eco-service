住宅エコサービス ホームページ一式
====================================

【ファイル構成】
index.html            メインページ
style.css             デザイン・スマホ対応
script.js             メニュー、電話・LINE、フォームの動作
config.js             電話番号、LINE URL、通知メール等の設定
privacy.html          プライバシーポリシー
README_公開手順.txt   この説明書

【まずPCで確認する】
1. ZIPファイルを展開する（解凍する）。
2. index.html をダブルクリックしてブラウザで開く。
3. メニュー、サービス案内、フォームの入力欄などを確認する。
4. インターネット接続時、写真とWebフォントは外部から読み込みます。

【公開前に必ず設定する】
config.js をテキストエディタで開き、空欄を実際の情報に変更します。
- phone: 電話番号（例 "0312345678"）
- lineUrl: LINE公式アカウントの友だち追加URL（https://lin.ee/...）
- contactEmail: 問い合わせ通知を受け取りたいメールアドレス
- address: 公開する住所（自宅住所を出したくない場合は、掲載方法を検討）
- hours: 実際の営業時間・定休日
- licenses: 実際に保有し、当該事業で表示できる資格・許認可のみ

会社の所在地、法人か個人事業か、資格・許認可、電話番号などを推測で記載しないでください。
電話番号やLINEが未設定の場合、問い合わせボタンはフォームへ案内するようになっています。

【問い合わせフォームの設定】
フォームは FormSubmit の AJAX エンドポイントを利用する実装です。
1. config.js の contactEmail に通知先メールアドレスを入力する。
2. サイトをHTTPSの公開URLにアップロードする。
3. 公開したサイトから、自分でテスト送信する。
4. 初回は FormSubmit から届く認証メールで送信先を有効化する必要がある場合があります。メール内の認証手順を完了してください。
5. 迷惑メールフォルダも確認し、受信・返信・スマホ表示をテストしてください。

注意：
- ブラウザ側だけでフォームの完全なスパム防止や機密情報保護はできません。
- 外部フォームサービスを使うため、サービスの利用規約・プライバシーポリシー・運用条件を確認してください。
- 本番公開前に、プライバシーポリシーの外部サービス記載と連絡先を実際の運用に合わせてください。
- メール通知が必ず届くとは限らないため、公開前のテストが必要です。
- APIキー、パスワードなどの秘密情報をHTMLやJavaScriptに書かないでください。

【無料で公開する例：GitHub Pages】
1. GitHub.com でアカウントを作成／ログインする。
2. 新しい公開リポジトリを作成する。例: jutaku-eco-service-site
3. index.html、style.css、script.js、config.js、privacy.html をリポジトリ直下へアップロードする。
4. リポジトリの Settings → Pages を開く。
5. Build and deployment の Source で Deploy from a branch を選ぶ。
6. Branch を main、フォルダを /(root) にして Save。
7. 公開処理後、Pages画面に表示されるURLを開いて確認する。
公式手順：https://docs.github.com/en/pages/quickstart

GitHub Pagesは静的サイト向けのホスティングです。フォーム送信は外部サービスに依存します。
公開URLができたら、電話・LINE・フォームをすべてテストしてください。

【別の公開方法】
Netlifyなどの静的サイトホスティングにフォルダをアップロードする方法もあります。
独自ドメインは必須ではありません。必要になってから取得を検討してください。

【写真について】
このテンプレートはUnsplashの画像URLを利用しています。画像URLや利用条件は変更されることがあります。
会社の実際の施工実績に見えるような使い方は避け、公開前に画像の利用条件を確認し、できれば自社で撮影した写真または利用許諾の明確な写真へ置き換えてください。

【公開前チェックリスト】
[ ] 屋号・事業内容に誤りがない
[ ] 電話番号・LINE URL・通知メールを設定した
[ ] 住所・営業時間・資格情報を確認した
[ ] 架空の施工実績や保証内容を載せていない
[ ] プライバシーポリシーを実運用に合わせた
[ ] フォームの初回認証と送受信テストを完了した
[ ] スマホとPCの両方で確認した
[ ] リンク切れ・誤字・写真の表示を確認した
